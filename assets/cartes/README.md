# Visuels des cartes

Placer ici les images des 53 cartes, nommées par numéro sur deux chiffres :

```
01.jpg   La Destinée
02.jpg   L'Étoile de l'Homme
...
53.jpg   La Carte Bleue
```

Formats acceptés : `.jpg` (le code cherche `NN.jpg`). En l'absence d'image, la fiche
affiche simplement le numéro de la carte — l'application fonctionne sans.

## Droits

Les illustrations de l'Oracle de Belline sont protégées. N'utiliser ici que des
reproductions pour un usage strictement personnel, et **ne pas publier ce dossier**
dans un dépôt public si tu y ajoutes des scans. Au besoin, garder les images en local
et ne pousser que le code.
